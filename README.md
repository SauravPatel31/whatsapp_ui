# WhatsApp UI  

A **responsive WhatsApp UI** built with **Flutter** and **Dart**, featuring **state management** using **Provider**. This project ensures seamless performance across **mobile** and **web** platforms by utilizing **orientation-based design** for responsiveness.  

## Features  
✨ **WhatsApp-inspired UI**: A clean and modern interface, inspired by WhatsApp's design principles.  
✨ **Responsive Design**: Adapts seamlessly to both app and web platforms, with orientation-based layouts for an optimal user experience.  
✨ **Provider for State Management**: Efficient and scalable state management using the Provider package.  
✨ **Icons**: Includes visually appealing icons to mimic WhatsApp's design.  

## Technologies Used  
- **Flutter**: Cross-platform UI framework.  
- **Dart**: Programming language for Flutter.  
- **Provider**: State management solution.  
- **Responsive Design**: Orientation and layout adjustments for mobile and web.  

## Getting Started  

### Prerequisites  
Ensure you have the following installed on your machine:  
- Flutter SDK: [Install Flutter](https://docs.flutter.dev/get-started/install)  
- Dart SDK (comes with Flutter)  
- A code editor like [Visual Studio Code](https://code.visualstudio.com/) or [Android Studio](https://developer.android.com/studio)  

### Installation  

1. Clone the repository:  
   ```bash  
   git clone https://github.com/SauravPatel31/whatsapp_ui.git  
   ```  
2. Navigate to the project directory:  
   ```bash  
   cd whatsapp_ui  
   ```  
3. Fetch dependencies:  
   ```bash  
   flutter pub get  
   ```  
4. Run the app:  
   ```bash  
   flutter run  
   ```  

The application will launch on a connected device or emulator.
